## Реализация runner

Напиши `runner.js` для выполнения многошаговых сценариев тестирования агента.

### Интерфейс

Запускай runner командой:

```text
node runner.js <test-dir> --agent <adapter> [--params <string>]
```

Храни сценарий теста в `<test-dir>/scenario.js`. Экспортируй из него асинхронную функцию:

```js
module.exports = async ({ testDir, workspaceDir, run, continueRun }) => {
  const session = await run('Выполни инструкцию.');

  // Измени файлы в workspaceDir.

  await continueRun(session, 'Снова выполни актуальную инструкцию.');
};
```

Разреши сценарию выполнять произвольный JavaScript и изменять содержимое `workspaceDir`. Запрети сценарию напрямую вызывать CLI менеджеров агентов.

### Подготовка

1. Очисти `<test-dir>/output/`.
2. Скопируй содержимое `<test-dir>/workspace/` в `<test-dir>/output/`, если `workspace/` существует.
3. Скопируй [](<../ai_artifacts/integrated_with_other_en/codex/skills/>) в `<test-dir>/output/.agents/skills/`.
4. Выполни `scenario.js`, передав `workspaceDir` = `<test-dir>/output/`.

### API сценария

- `run(prompt)` — запусти новую сессию агента в `workspaceDir`, дождись завершения и верни дескриптор сессии.
- `continueRun(session, prompt)` — продолжи указанную сессию в том же `workspaceDir`, дождись завершения и верни обновлённый дескриптор.
- Сохраняй идентификатор сессии, полученный из потока менеджера агента, и используй его при продолжении.
- Передавай параметры `--params` каждому запуску агента.

### Адаптеры

Возьми адаптеры и парсинг потоков из [](<../tests/runner.js>) за основу. Реализуй в каждом адаптере отдельные операции запуска и продолжения сессии. Определяй команды конкретных менеджеров агентов только внутри блока адаптеров.

Для `agy` прочитай [](<../.agent/skills/antigravity-cli/>). Для `codex` прочитай [](<../.agent/skills/codex-cli/>).

### Требования

- Используй только стандартную библиотеку Node.js.
- Установи тайм-аут 120 секунд для каждого запуска агента.
- Прерывай сценарий при ошибке, ненулевом коде агента или тайм-ауте.
- Выводи начало и результат каждого шага сценария.
- Возвращай код `0` при успешном выполнении всего сценария и `1` при ошибке.
- Обеспечь кроссплатформенную работу.
