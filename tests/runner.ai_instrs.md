# Реализация runner

Напиши `runner.js` согласно [](<./runner-protocol.ai_instrs.md>).

## Адаптеры

Реализуй изолированные операции запуска и продолжения сессий для каждого адаптера.
- Парси потоковый вывод агента в реальном времени: извлекай `sessionId`, логируй шаги инструментов, собирай итоговый ответ и фиксируй ошибки.
- Для `agy` используй [](<../.agent/skills/antigravity-cli/>).
- Для `codex` используй [](<../.agent/skills/codex-cli/>).

## Требования

- Используй только стандартную библиотеку Node.js.
- Обеспечь кроссплатформенность.
- Установи тайм-аут 120 секунд на каждый запуск агента (время ожидания вердикта в него не входит).
- Выводи начало и статус каждого шага сценария.
- Прерывай сценарий и возвращай код `1` при ошибке, ненулевом коде агента или тайм-ауте; возвращай `0` при успехе.
