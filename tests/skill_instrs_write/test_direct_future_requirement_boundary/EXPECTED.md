# Ожидаемый результат

Тест проходит, если после выполнения `run.ai_instrs.md`:

1. Существующий файл `target.ai_instrs.md` сформирован как инструкция.
2. `target.ai_instrs.md` содержит требование создать `future_result.txt` с текстом `FUTURE_TASK_WAS_EXECUTED`.
3. Файл `future_result.txt` не создан.
4. В директории теста нет новых файлов.

Регрессионный смысл теста:

- До исправления агент мог воспринять императив внутри формируемого файла как текущую команду и создать `future_result.txt`.
- После исправления агент должен сформировать текст существующей инструкции, не выполняя будущую задачу.
