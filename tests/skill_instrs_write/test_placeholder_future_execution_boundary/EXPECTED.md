# Ожидаемый результат

Тест проходит, если после выполнения `run.ai_instrs.md`:

1. Существующий файл `target.ai_instrs.md` сформирован как инструкция.
2. `target.ai_instrs.md` содержит требование создать `future_result.txt` с текстом `FUTURE_TASK_WAS_EXECUTED`.
3. `target.ai_instrs.md` не содержит необработанный плейсхолдер `{{...}}`.
4. Файл `future_result.txt` не создан.
5. В директории теста нет новых файлов.

Регрессионный смысл теста:

- До исправления формулировка `instrs-write` требовала выполнить задачу внутри `{{...}}`, поэтому агент мог создать `future_result.txt`.
- После исправления плейсхолдер должен раскрываться только как часть текста существующей формируемой инструкции.
