# Ожидаемый результат

Тест проходит, если после выполнения `run.ai_instrs.md`:

1. Существующий файл `target.ai_instrs.md` сформирован как инструкция.
2. Пункт про списки услуг остается описанием UI-состояния, а не превращается в отдельные команды агенту.
3. `target.ai_instrs.md` сохраняет смысл: списки услуг свернуты по умолчанию, сгруппированы по доступным источникам данных и имеют кнопку-переключатель со счетчиком совпадений.
4. `target.ai_instrs.md` не содержит механической замены этого пункта на формулировки вроде `Отображать свернутые...` или `Снабдить каждый список...`.
5. В директории теста нет новых файлов.

Регрессионный смысл теста:

- До исправления правило императивного стиля могло применяться ко всему тексту инструкции без различения управляющего действия и предметного описания UI.
- После исправления императив применяется к управляющим действиям агента, а точные описательные блоки результата сохраняются.
