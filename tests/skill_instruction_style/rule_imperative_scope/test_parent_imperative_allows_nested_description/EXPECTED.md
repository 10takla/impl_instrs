# Ожидаемый результат

Тест проходит, если после выполнения `run.ai_instrs.md`:

1. Существующий файл `target.ai_instrs.md` сформирован как инструкция.
2. Управляющая рамка раздела сохраняет побуждение к действию: агент должен реализовать UI-интерфейс.
3. Вложенный список основных блоков остается описанием структуры интерфейса.
4. Пункты списка не переписаны механически в отдельные команды вида `Добавь блок...`, `Создай блок...`, `Отобрази блок...`.
5. В директории теста нет новых файлов.

Регрессионный смысл теста:

- До исправления агент мог оценивать каждую строку списка отдельно и требовать императивной формы для каждого пункта.
- После исправления агент должен учитывать родительскую управляющую рамку раздела и сохранять описательный стиль вложенных структурных списков.
