# Ожидаемый результат

Тест проходит, если после выполнения `run.ai_instrs.md`:

1. Существующий файл `target.ai_instrs.md` сформирован как инструкция.
2. Действия агента сформулированы в прямом императивном стиле.
3. `target.ai_instrs.md` сохраняет смысл: проверить `input.md`, записать замечания в `review.md`, сначала открыть файл полностью.
4. `target.ai_instrs.md` не содержит размывающие конструкции `Нужно проверить` и `Рекомендуется сначала`.
5. В директории теста нет новых файлов.

Регрессионный смысл теста:

- Исправление не должно отменять императивный стиль полностью.
- После исправления стиль должен различать управляющие действия агента и описательные блоки результата.
