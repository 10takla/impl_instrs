# Ожидаемый результат

## Контрольная точка `первый запуск`

1. Первый запуск создаёт в `result.txt` состояние `FIRST_STATE` и сохраняет строку `KEEP`.
2. Агент не создаёт дополнительных файлов.

## Итоговое состояние

1. После изменения инструкции второй запуск в той же сессии заменяет `FIRST_STATE` на `CURRENT_STATE`.
2. Строка `KEEP` сохраняется.
3. `requirements.ai_instrs.md` содержит актуальную инструкцию перехода от `FIRST_STATE` к `CURRENT_STATE`.
4. Агент не создаёт дополнительных файлов.
