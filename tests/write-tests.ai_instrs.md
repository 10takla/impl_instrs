# Написание нового теста

Создай новый тест в `cases/`.

## Структура

Размести тест в иерархии групп:

```text
cases/
└── <группа>/
    ├── ABOUT_TEST.md
    └── <тест>/
        ├── ABOUT_TEST.md
        ├── EXPECTED.md
        ├── scenario.js
        └── workspace/      # опционально
```

- Именуй группы и тесты в `snake_case`.
- Добавь `ABOUT_TEST.md` с кратким описанием на каждом созданном уровне иерархии.
- Помести исходное состояние файлов в `workspace/`, если оно требуется до запуска сценария.
- Опиши проверяемое поведение и наблюдаемый результат в `EXPECTED.md`.

## Сценарий

Экспортируй из `scenario.js` асинхронную функцию:

```js
module.exports = async ({ testDir, workspaceDir, run, continueRun, checkpoint }) => {
  const session = await run('Выполни инструкцию.');

  await checkpoint('первый запуск');

  // Измени файлы в workspaceDir.

  await continueRun(session, 'Продолжи работу с актуальным состоянием.');
};
```

- Используй `run(prompt)` для новой сессии.
- Используй `continueRun(session, prompt)` только для продолжения полученной сессии.
- После каждого запуска агента, за которым следует изменение `workspaceDir` или следующий запуск, вызывай `await checkpoint(label)` до следующего действия.
- Опиши ожидаемое состояние каждой контрольной точки и её метку в `EXPECTED.md`.
- Изменяй состояние тестового рабочего пространства через `workspaceDir`.
- Не проверяй ожидаемое поведение агента в `scenario.js` через сравнения, утверждения, регулярные выражения или эвристики.
- Не связывай ход сценария со временем, случайностью, сетью, операционной системой, порядком обхода файлов или неоговорённым форматированием.
- Не вызывай напрямую CLI менеджеров агентов из сценария.
- Не создавай `output/`: его подготавливает [runner](./runner.ai_instrs.md#подготовка).

## Стиль кода

**expression-oriented style** — стиль, ориентированный на выражения:

- промежуточные переменные заменяются встроенными выражениями (**inlining**);
- функции объединяются через **композицию** или цепочки вызовов;
- уменьшается количество изменяемого состояния и отдельных инструкций (**statements**).
