# Запуск теста

Получи путь к тесту, адаптер агента и необязательные параметры запуска.

1. Запусти из корня проекта:

   ```text
   node tests2/runner.js <test-dir> --agent <adapter> [--params <string>]
   ```

2. Дождись завершения всего сценария. Считай ненулевой код runner, ошибку шага или тайм-аут провалом теста.
3. Прочитай `<test-dir>/EXPECTED.md` и фактическое состояние `<test-dir>/output/`.
4. Сопоставь каждый ожидаемый результат с наблюдаемым состоянием и выводом runner.
5. Вынеси вердикт `PASS` только при выполнении всех ожиданий; иначе вынеси `FAIL` и перечисли расхождения.

Учитывай, что runner очищает `output/` перед каждым запуском согласно разделу [«Подготовка»](./runner.ai_instrs.md#подготовка).
