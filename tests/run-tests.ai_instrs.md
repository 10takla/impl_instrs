# Запуск теста

**Входные данные:** `<test-dir>`, `--agent <adapter>`, `[--params <string>]`.

**Алгоритм** (протокол runner — [](<./runner-protocol.ai_instrs.md>)):

1. Прочитай `<test-dir>/EXPECTED.md` и `<test-dir>/workspace/`.
2. Запусти из корня проекта интерактивный процесс `runner.js`.
3. Читай вывод процесса. Не учитывай `.agents/skills/` в `output/` как результат агента.
4. При появлении маркера `=== AWAITING VERDICT: CONTINUE | FAIL <причина> ===`:
   - Сопоставь актуальное состояние `<test-dir>/output/` с разделом контрольной точки в `EXPECTED.md` по смыслу (точное содержимое проверяй только при явно заданном формате).
   - Отправь в stdin `FAIL <причина>`, если контрольная точка отсутствует в `EXPECTED.md` или ожидания не выполнены.
   - Отправь в stdin `CONTINUE` и продолжи чтение вывода, если ожидания выполнены.
5. После завершения runner сопоставь итоговое состояние `<test-dir>/output/` и вывод процесса с итоговыми ожиданиями в `EXPECTED.md`.
6. Вынеси вердикт:
   - `PASS` — при коде завершения `0` и выполнении всех ожиданий.
   - `FAIL <расхождения>` — при ненулевом коде, ошибке, тайм-ауте агента или нарушении ожиданий.
