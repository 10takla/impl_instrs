# Ожидаемый результат

1. Существующий файл `target.md` сформирован как инструкция.
2. Пункт про списки услуг остается описанием UI-состояния, а не превращается в отдельные команды агенту.
3. `target.md` сохраняет смысл: списки услуг свернуты по умолчанию, сгруппированы по доступным источникам данных и имеют кнопку-переключатель со счетчиком совпадений.
4. `target.md` не содержит механической замены этого пункта на формулировки вроде `Отображать свернутые...` или `Снабдить каждый список...`.
5. В директории нет новых непредусмотренных файлов.
