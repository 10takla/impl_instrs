# Ожидаемый результат

1. Первый запуск создаёт в `result.txt` состояние `FIRST_STATE`; сценарий прерывается, если это не выполнено.
2. После изменения инструкции второй запуск в той же сессии заменяет `FIRST_STATE` на `CURRENT_STATE`.
3. Строка `KEEP` сохраняется.
4. `requirements.ai_instrs.md` содержит актуальную инструкцию перехода от `FIRST_STATE` к `CURRENT_STATE`.
5. Агент не создаёт дополнительных файлов.
