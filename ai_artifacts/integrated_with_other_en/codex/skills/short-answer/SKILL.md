---
name: "impl-instrs:short-answer"
description: "DO NOT TRIGGER AUTOMATICALLY. Workflow for explicit invocation only via /slash command. Add a short concise summary at the end of detailed responses."
---

When generating a detailed response, a brief, concise summary of it must be added to the very end of the message.
If the response is initially short, nothing needs to be added.
This rule must not affect the content, style, and generation process of the response itself.
