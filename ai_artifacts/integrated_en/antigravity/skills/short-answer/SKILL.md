---
name: "impl-instrs:short-answer"
description: "DO NOT TRIGGER AUTOMATICALLY. Workflow for explicit invocation only via /slash command. Add a short concise summary at the end of detailed responses."
---

When generating a detailed response, add a short, concise summary to the very end of the message. 
If the response is short by default, nothing needs to be added. 
This rule must not affect the content, style, or generation process of the response itself.
