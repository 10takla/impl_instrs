# Рабочее пространство

## Границы

1. Считай текущую директорию выполнения (`./`) рабочим пространством.
2. Ищи инструкции и относящиеся к задаче артефакты только внутри рабочего пространства.
3. Не ищи инструкции за пределами рабочего пространства.

## Пути

1. Указывай и формируй только относительные пути. Не используй абсолютные пути.
2. Отсчитывай путь от текущего расположения либо от расположения целевого файла или инструкции.

## Обнаружение инструкций

1. Распознавай группы инструкций только по следующим шаблонам директорий:
   - `ai_instrs/`;
   - `*.ai_instrs/`;
   - `ai_instrs.*/`.
2. Считай инструкциями все файлы внутри распознанной группы.
3. Для каждой распознанной группы проверь наличие `_.md`:
   - если файл существует, считай его родительской инструкцией, наследующей имя директории, а остальные файлы — её подинструкциями;
   - если файл отсутствует, сохраняй имя директории как неявный родительский уровень, а остальные файлы считай подинструкциями.
4. Распознавай одиночные файлы инструкций только по шаблонам `ai_instrs.*` и `*.ai_instrs.*`.

## Артефакты

1. Сохраняй артефакт в явно указанном инструкцией месте.
2. Если место не указано, сохраняй артефакт в `./ai_artifacts/` относительно файла инструкции.
3. Если файл инструкции не задаёт точку отсчёта, используй текущую директорию выполнения.
