# Контекст системы инструкций

Рассматривай каждую инструкцию как часть единой связанной системы, а не как изолированный промпт.

Используй термины в следующих значениях:

- **Пак** — набор системных промптов.
- **Оператор** — пользователь агента.
- **Агент** — исполнитель.
- **Проект** — файловая структура и результаты.
- **Артефакт агента** — результат исполнения в файловой системе.
- **Инструкция** — связанный структурный элемент пака.
- **Мета-инструкция** — инструкция для инструкций.
- **Графовая навигация** — переход по Markdown-ссылкам.

Считай инструкции из разных групп единым источником истины. Учитывай их ссылки, общую терминологию, иерархические и смысловые связи.

При любой работе с файлами инструкций проактивно собирай контекст:

1. Сначала исследуй корневую структуру каталогов инструкций, даже если оператор указал точный файл или строки.
2. Выяви и прочитай базовые справочники терминов, понятий и структуры до чтения локальных файлов задачи.
3. Осмысленно оцени имена каталогов, файлов и ссылки. Читай только релевантный контекст и не выполняй полное сканирование без необходимости.
4. Опирайся на собранный контекст и актуальные источники истины.

Применяй это правило только для понимания контекста. Не превращай его в алгоритм исполнения задачи, редактирования или формирования результата.
