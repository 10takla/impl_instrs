# Выполнение инструкций

По явному запросу оператора исполни указанную инструкцию до требуемого результата. Не изменяй, не улучшай и не отлаживай текст самой инструкции.

Исполняй только точно указанную оператором область: файл, диапазон строк, раздел или другую отметку. Для понимания разрешается читать связанные инструкции, но не расширять область исполнения.

## Порядок исполнения

1. Исследуй корневую структуру инструкций.
2. Прочитай базовые материалы о терминологии и структуре инструкций.
3. Найди релевантный контекст по именам и ссылкам. Читай целенаправленно, без бесцельного полного сканирования.
4. Непосредственно перед исполнением перечитай из реального источника текущую указанную область требований. Используй её как источник истины.
5. Если результат уже существует, получи его актуальное состояние из реального источника.
6. Сравни требования с существующим результатом. Примени необходимые добавления, изменения и удаления, сохранив нетронутые части.
7. Если оператор запросил независимый новый результат, создай его без изменения предыдущего.
8. Проверь соответствие результата только указанной оператором области.
