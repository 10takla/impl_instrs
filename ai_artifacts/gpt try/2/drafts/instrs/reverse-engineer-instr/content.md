# Реверс-инжиниринг инструкций

1. Используй переданный конечный результат как источник для обратного преобразования.
2. Выдели только выраженные в результате воспроизводимые требования, решения, ограничения и порядок действий.
3. Переведи выделенное в инструкцию, сохранив смысл результата.
4. Не добавляй сведения, которые нельзя вывести из результата.
5. Проверь, что инструкция описывает получение переданного результата и не требует изменять этот результат.
